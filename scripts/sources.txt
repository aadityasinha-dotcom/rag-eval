# Corpus manifest, read by scripts/fetch_corpus.py.
# One entry per line:
#   <url> [<target dir/file relative to corpus/>] [subdir=<dir inside archive>] [sha256=<hex>]
# Blank lines and lines starting with # are ignored.
#
# Archives (.zip, .tar.gz, .tgz, .tar) are extracted into corpus/<target>/
# (or corpus/ itself if no target is given). With subdir=, only that directory
# is extracted and its prefix removed. Anything else is saved as a file.
